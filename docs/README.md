## Project Overview
Team CKAV proposes an Integrated IoT Ecosystem for precision agriculture: a distributed, predictive analytics framework for the real-time preservation of stored grains. We move from reactive manual inspections to a conceptual framework that tracks CO2, temperature, and moisture in real-time to detect and prevent hotspots before spoilage occurs.
